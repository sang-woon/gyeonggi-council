# 읽기 전용 모드 사용자 가이드

이 문서는 rhwp-studio가 폰트 누락을 감지하여 자동으로 읽기 전용 모드로 전환하는 동작을 설명합니다.

## 왜 읽기 전용 모드가 필요한가

HWP 문서에 사용된 폰트가 사용자의 컴퓨터(특히 모바일)에 설치되어 있지 않으면, 글자가 다른 폰트로 대체되어 표시됩니다. 이 상태에서 문서를 편집·저장하면 **다른 사용자에게 깨진 문서로 보일 위험**이 있습니다.

rhwp-studio는 문서를 열 때 폰트 가용성을 자동 평가하여, 누락된 폰트가 많으면 사용자가 본의 아니게 원본을 손상시키는 것을 방지합니다.

## 모드 종류

| 모드 | 화면 표시 | 편집 가능 |
|------|----------|---------|
| 일반 편집 | 배너 없음 | ✅ |
| 경고 표시 | 노란 배너 | ✅ |
| 자동 읽기 전용 | 빨간 배너 + 도구 회색 | ❌ |
| 강제 편집 | 빨간 경고 배너 | ✅ (사용자 동의 후) |

### 일반 편집 (누락률 < 10%)

대부분의 폰트가 정상이면 배너 없이 평소처럼 편집할 수 있습니다.

### 경고 표시 (10% ~ 30% 누락)

```
ⓘ 이 문서의 폰트 N종이 시스템에 없습니다.    [자세히] [×]
```

- 노란 배너가 상단에 표시됩니다.
- **편집은 가능**하지만, 누락된 폰트의 글자는 다른 폰트로 보일 수 있습니다.
- "자세히"를 누르면 어떤 폰트가 누락됐는지 볼 수 있습니다.
- "×"로 배너를 닫을 수 있습니다.

### 자동 읽기 전용 (≥ 30% 누락, 모바일은 ≥ 60%)

```
⚠ 읽기 전용 — 폰트 N종이 없어 ...    [자세히] [편집 강제 활성화]
```

- **빨간 배너**가 표시되고, **편집이 자동으로 차단**됩니다.
- 도구 상자와 서식 도구가 회색으로 표시됩니다.
- 모바일 환경은 시스템 폰트가 적기 때문에 임계치가 60%로 더 관대합니다.

### 강제 편집 (사용자 동의 후)

자동 읽기 전용 상태에서 "편집 강제 활성화" 버튼을 누르면:

```
"폰트가 없는 글자는 다르게 보일 수 있고, 저장 시
원본 문서가 손상될 위험이 있습니다.

그래도 편집을 진행하시겠습니까?"

[취소] [확인]
```

확인하면 편집이 가능해지지만, **빨간 경고 배너는 계속 표시**되어 위험 상태임을 인지시킵니다.

```
⚠ 강제 편집 중 — 폰트 N종 누락. 저장 시 손상 가능. [자세히] [읽기 전용으로]
```

"읽기 전용으로" 버튼을 누르면 다시 자동 읽기 전용 상태로 복귀합니다.

## 폰트 가용성 자세히 보기

배너의 "자세히" 버튼을 누르면 다이얼로그가 표시됩니다:

| 폰트명 | 상태 | 치환 결과 |
|--------|------|----------|
| 함초롬바탕 | 🟢 번들 OK | |
| 맑은 고딕 | 🔵 시스템 OK | |
| 한컴바탕 | 🟡 치환됨 | 함초롬바탕 |
| HY신명조 | 🔴 누락 | |

| 상태 | 의미 |
|------|------|
| 🟢 번들 OK | 앱에 내장된 폰트로 정상 표시 |
| 🔵 시스템 OK | 사용자 OS에 설치된 폰트로 정상 표시 |
| 🟡 치환됨 | 비슷한 폰트로 자동 치환됨 (모양 차이 가능) |
| 🔴 누락 | 어떤 폰트로도 매칭 안 됨 (글자 깨질 가능성) |

## 모바일 환경 (Capacitor)

Android/iOS 환경에서는 사용 가능한 폰트가 적기 때문에 임계치가 다음과 같이 적용됩니다:

| 환경 | 자동 읽기 전용 |
|------|-------------|
| 데스크톱 | 누락률 ≥ 30% |
| 모바일 | 누락률 ≥ 60% |

10~60% 구간은 모바일에서도 노란 배너만 표시되어 편집이 가능합니다.

## 자주 묻는 질문

### Q. 읽기 전용 모드를 항상 끄고 싶어요

현재는 매 문서마다 사용자가 "편집 강제 활성화"로 진입해야 합니다. 향후 환경설정에서 영구 비활성화 옵션이 추가될 수 있습니다.

### Q. 다이얼로그의 "치환됨"이 정확한가요?

폰트 치환표는 한컴 webhwp 기준 약 200건의 매핑을 사용합니다. 비슷한 모양의 대체 폰트로 매핑하지만, 글자 폭이 미세하게 다를 수 있습니다.

### Q. 나는 폰트가 없어도 모양만 다르면 OK인데요

"편집 강제 활성화"를 누르면 됩니다. 다만 저장한 문서를 폰트가 있는 환경에서 다시 열면 원본 모양으로 돌아오므로, 단순 표시 차이라면 문제 없습니다. 글자 위치 기반 정렬·표·도형이 어긋나지 않는 한 안전합니다.
