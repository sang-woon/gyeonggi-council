# Play Console 콘텐츠 등급 설문 (IARC) 응답 가이드

Play Console > 정책 > 앱 콘텐츠 > 콘텐츠 등급 설문에서 정확한 답변을 입력하기 위한 가이드. 본 앱은 **HWP 문서 뷰어**로, 어떠한 사용자 생성 콘텐츠나 부적절한 요소도 포함하지 않으므로 모든 항목 "아니요"로 응답.

## 1. 카테고리 선택

| 항목 | 답변 |
|------|------|
| 앱 카테고리 | **참조, 뉴스, 교육** (Reference / News / Educational) |
| 본 앱이 게임인가요? | 아니요 |

## 2. 폭력성 (Violence)

| 질문 | 답변 |
|------|------|
| 폭력 행위 묘사 | 아니요 |
| 사실적 폭력 | 아니요 |
| 잔혹·자혹한 묘사 | 아니요 |
| 자해·자살 묘사 | 아니요 |
| 동물 학대 | 아니요 |

근거: HWP 문서를 사용자가 자체 보관한 파일을 표시할 뿐, 앱 자체가 어떤 콘텐츠도 제공하지 않음.

## 3. 성적 콘텐츠 (Sexuality)

| 질문 | 답변 |
|------|------|
| 노출·성적 묘사 | 아니요 |
| 성적 행위 | 아니요 |
| 성적 함의 | 아니요 |

## 4. 비속어·욕설 (Language)

| 질문 | 답변 |
|------|------|
| 비속어 | 아니요 |
| 모욕적 언어 | 아니요 |
| 차별적 언어 | 아니요 |

## 5. 통제된 물질 (Controlled Substances)

| 질문 | 답변 |
|------|------|
| 마약·약물 | 아니요 |
| 알코올 | 아니요 |
| 담배 | 아니요 |

## 6. 도박 (Gambling)

| 질문 | 답변 |
|------|------|
| 시뮬레이션 도박 | 아니요 |
| 실제 도박 | 아니요 |

## 7. 사용자 상호작용 (User Interaction)

| 질문 | 답변 |
|------|------|
| 사용자가 다른 사용자와 상호작용할 수 있나요? | **아니요** |
| 사용자 위치를 공유하나요? | 아니요 |
| 사용자 생성 콘텐츠가 다른 사용자에게 공유되나요? | 아니요 |

근거: 본 앱은 사용자 디바이스 내에서만 동작. 다른 사용자와의 통신 기능 없음.

## 8. 기타 항목

| 질문 | 답변 |
|------|------|
| 디지털 구매가 있나요? (인앱 결제) | 아니요 |
| 사용자가 정보·데이터를 공유할 수 있나요? | 아니요 |
| 광고가 표시되나요? | 아니요 |

## 9. 결과 등급 (예상)

위 응답에 따른 예상 등급:

| 지역 | 등급 |
|------|------|
| IARC 글로벌 | **3+** (전체 이용가) |
| 한국 GRAC | **전체이용가** |
| 미국 ESRB | **Everyone** |
| 유럽 PEGI | **3** |
| 호주 ACB | **G** (General) |

## 10. 주의 사항

- **HWP 문서 자체는 사용자 자체 콘텐츠**이지만, 본 앱이 "사용자 생성 콘텐츠 공유 기능"을 제공하지 않으므로 7번 항목은 "아니요"로 응답
- 정부·공공 앱은 일반적으로 등급 심사를 통과하기 쉬우나, 한 항목이라도 "예"로 응답 시 추가 검증·연령 제한 부과 가능
- 응답을 제출하면 등급이 자동 발급되며, 제출 후 1~2시간 내 인증 메일 수신

## 11. 항소·정정

응답 오류 발견 시 Play Console > 정책 > 콘텐츠 등급 설문 > 다시 작성. 단, 등급이 발급된 후 변경하면 새 심사가 필요할 수 있음.
