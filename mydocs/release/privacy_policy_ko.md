# 개인정보 처리방침 — 경기도의회 HWP 뷰어

본 개인정보 처리방침은 "경기도의회 HWP 뷰어" 안드로이드 앱(이하 "본 앱")에 적용됩니다.

**시행일자**: (앱 출시일 기준 작성 — 단계 5 진입 시 확정)
**최종 개정일**: 동일

## 1. 본 앱이 수집하는 개인정보

**본 앱은 어떠한 개인정보도 수집하지 않습니다.**

- 사용자 식별 정보 (이름·이메일·전화번호 등) 미수집
- 위치 정보 미수집
- 단말기 식별자 (광고 ID·IMEI 등) 미수집
- 앱 사용 분석 정보 미수집

## 2. 파일 접근 권한

본 앱은 사용자가 명시적으로 선택한 HWP/HWPX 문서 파일만 읽습니다.

- **저장소 권한**: Android 시스템의 Storage Access Framework(SAF)를 통해 사용자가 직접 선택한 파일에만 접근. 광범위한 저장소 권한(`READ_EXTERNAL_STORAGE` 등)을 요구하지 않습니다.
- **외부 인텐트로 열기**: 다른 앱(파일 매니저, 메일 첨부 등)에서 .hwp 파일을 본 앱으로 열 때, 해당 파일만 일회적으로 처리합니다.
- **저장 위치**: 사용자가 변환·저장 시 디바이스의 `문서/rhwp/` 폴더에 저장됩니다. 외부로 전송되지 않습니다.

## 3. 데이터 외부 전송

**본 앱은 어떤 데이터도 외부 서버에 전송하지 않습니다.**

- 모든 HWP 파싱·렌더링은 사용자 디바이스 내에서만 수행됩니다 (WebAssembly 기반).
- 광고 SDK·분석 SDK·소셜 로그인 SDK 등 제3자 서비스 통합이 없습니다.
- `INTERNET` 권한이 등록되어 있으나, 실제로 외부 통신을 수행하지 않습니다 (Android WebView 컴포넌트의 시스템적 요구사항).

## 4. 쿠키 및 추적

본 앱은 쿠키나 유사 추적 기술을 사용하지 않습니다.

## 5. 어린이의 개인정보

본 앱은 만 14세 미만 어린이로부터 개인정보를 수집하지 않습니다. 어떤 사용자에게도 개인정보를 요구하지 않으므로 해당 사항이 없습니다.

## 6. 개인정보 처리방침의 변경

본 방침이 변경될 경우, 앱 내 또는 본 페이지에 변경 사항을 공지합니다. 중요한 변경 시 사용자에게 사전 고지합니다.
