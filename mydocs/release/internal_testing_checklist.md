# 내부 테스트 검증 체크리스트

내부 테스트 트랙(Play Console)에 AAB 업로드 후, 테스터에게 전달하는 검증 가이드. 인쇄 또는 모바일 화면 분할로 사용.

## 사전 준비

| 항목 | 확인 |
|------|------|
| 안드로이드 폰 (Android 7.0 / API 24 이상) | □ |
| 본 앱 설치 (Play Console 내부 테스트 링크) | □ |
| 샘플 .hwp 파일 1개 (메일·메신저로 전송하거나 다운로드) | □ |
| 큰 파일(10MB+) .hwp 1개 (선택, 메모리 검증용) | □ |

## A. 앱 실행 (단계 1 검증)

- [ ] 앱 아이콘 탭 → 앱 정상 실행
- [ ] 앱 아이콘 디자인 정상 표시 (네이비 + 흰 페이지 + '한')
- [ ] 첫 화면에 햄버거(☰) 메뉴 + 서식 도구 표시
- [ ] 상태 바 안전 영역 침범 없음 (노치/펀치홀 회피)
- [ ] 가로 모드 회전 → 자동 회전 + 레이아웃 정상

## B. 햄버거 메뉴 (단계 2 검증)

- [ ] 좌측 상단 햄버거(☰) 탭 → 좌측 슬라이드인 메뉴 출현
- [ ] 메뉴 외부 영역 탭 → 메뉴 닫힘
- [ ] 메뉴에서 "파일", "편집" 등 항목 존재
- [ ] "파일 > 열기" 또는 "새로 만들기" 선택 시 정상 동작

## C. 외부 인텐트로 .hwp 열기 (단계 3 검증)

- [ ] 메일·카카오톡·파일 매니저에서 .hwp 첨부 파일 길게 누르기
- [ ] "다음으로 열기" 메뉴에서 **본 앱이 후보로 노출**
- [ ] 본 앱 선택 시 자동으로 해당 파일이 로드됨
- [ ] 다운로드 폴더 등에서 .hwp 파일 탭 → 동일하게 본 앱이 후보 노출

## D. HWP 문서 렌더링 (핵심 검증)

- [ ] 표·그림 포함된 일반 .hwp 파일 → 정상 표시
- [ ] 한글 폰트 깨짐 없음 (또는 다음 항목 E 진행)
- [ ] 페이지 단위 부드러운 스크롤
- [ ] 핀치 줌으로 확대·축소
- [ ] 페이지 번호·구역·모드 표시줄 정상 표시 (하단)

## E. 폰트 누락 자동 읽기 전용 (Task #2 핵심)

- [ ] 폰트가 많이 누락되는 .hwp (한컴 전용 폰트 사용 문서) 열기
- [ ] **빨간 배너** 출현: "읽기 전용 — 폰트 N종이 시스템에 없어..."
- [ ] 도구 상자가 회색으로 비활성 (편집 차단 시각 표시)
- [ ] "자세히" 버튼 → 폰트 가용성 표 다이얼로그 표시
- [ ] "편집 강제 활성화" 클릭 → 모달 경고 → 확인 → 도구 활성화 + "강제 편집 중" 배너
- [ ] "읽기 전용으로" 버튼 → 다시 자동 읽기 전용 모드

## F. 저장 (선택)

- [ ] 메뉴 > 파일 > 다른 이름으로 저장 → 형식 선택 (HWP / SVG)
- [ ] 저장 위치 `Documents/rhwp/` 확인 (안드로이드 파일 매니저로 검증)
- [ ] 저장된 파일을 다른 안드로이드 앱(예: 카카오톡)에서 열기 시도 → 정상

## G. 큰 파일 메모리 (선택)

- [ ] 10MB 이상 .hwp 파일 열기 시도
- [ ] OOM 크래시 없음 (앱 강제 종료 안 됨)
- [ ] 페이지 스크롤 시 메모리 폭증 없음 (시스템 모니터로 확인 가능 시)

## H. 네트워크 검증 (선택, 보안)

- [ ] Wi-Fi/모바일 데이터 모두 끄고 비행기 모드
- [ ] 앱 정상 실행 + .hwp 파일 정상 표시
- [ ] 어떤 화면에서도 "네트워크 오류"/"연결 실패" 메시지 없음

## I. 일반 동작 + 시각적 만족도

- [ ] 앱 시작·종료 속도 (3초 이내)
- [ ] 회전 시 깜박임/멈춤 없음
- [ ] 한글 IME(천지인·삼성·구글 한글) 입력 정상 (편집 모드 시)
- [ ] 다크 모드(설정 시) 호환 또는 라이트 모드 고정 적용
