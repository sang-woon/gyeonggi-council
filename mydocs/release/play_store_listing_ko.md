## 자세한 설명 (최대 4000자)

```
경기도의회 HWP 뷰어는 한글(HWP/HWPX) 문서를 안드로이드 휴대전화·태블릿에서 빠르게 열어볼 수 있는 공식 뷰어 앱입니다. 별도 설치나 변환 없이, 한글 워드프로세서로 작성된 문서를 그대로 보여드립니다.

[주요 기능]
• 한글 HWP / HWPX 파일 열기
• 표 · 그림 · 서식이 포함된 복잡한 문서도 정확히 표시
• 페이지 단위 부드러운 스크롤 + 핀치 줌
• 외부 파일 매니저, 메일 첨부, 메신저에서 .hwp 파일 탭 시 본 앱이 후보로 표시
• Documents/rhwp/ 폴더로 변환·저장
• 광고 없음 · 인앱 결제 없음
• 오프라인 동작 (인터넷 연결 불필요)

[개인정보 보호]
• 사용자가 선택한 파일만 처리 (저장소 광범위 권한 요청 안 함)
• 어떤 데이터도 수집·전송하지 않음 — 모든 처리는 본 앱 내부에서만
• 사용자 분석 도구나 광고 SDK 미탑재
• 인터넷 통신 없음 (앱 자체는 인터넷 권한만 보유, 실제 외부 통신 안 함)

[기관 정보]
경기도의회의 HWP 문서 접근성 향상을 위해 제작된 공식 앱입니다. 오픈소스 rhwp 프로젝트 기반.

[지원 환경]
• Android 7.0 (Nougat, API 24) 이상
• 한글 운영체제 권장

[문의]
경기도의회 정보화담당
이메일: ggc.it.portal@gmail.com
```
