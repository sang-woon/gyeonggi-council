# 데이터 안전 섹션 — Google Play Console 입력 가이드

Play Console > 앱 콘텐츠 > 데이터 보안 (Data Safety) 섹션 응답안.

## 데이터 수집 (Data Collection)

> "이 앱이 사용자 데이터를 수집하나요?"

**답변**: **아니요 (No, this app does not collect any user data)**

다음 카테고리 모두 "수집 안 함":
- 위치 정보
- 개인 식별 정보
- 금융 정보
- 건강 및 피트니스
- 메시지
- 사진·동영상
- 오디오
- 파일·문서 (※ 사용자 디바이스 내 처리만, 외부 전송 없음)
- 캘린더·연락처
- 앱 활동·앱 정보·기기 ID
- 웹 검색 기록

> ⚠️ 주의: "파일·문서"는 본 앱이 .hwp 파일을 다루지만 "수집(Collection)"의 정의는 **외부 전송**을 포함합니다. 본 앱은 디바이스 내에서만 처리하므로 "수집 안 함"에 해당.

## 데이터 공유 (Data Sharing)

> "이 앱이 제3자와 사용자 데이터를 공유하나요?"

**답변**: **아니요 (No)**

## 보안 관행 (Security Practices)

| 항목 | 답변 |
|------|------|
| 데이터가 전송 중 암호화되나요? | 해당 없음 (외부 전송 없음) |
| 사용자에게 데이터 삭제 요청 권리가 제공되나요? | 해당 없음 (수집된 데이터 없음) |
| 이 앱이 패밀리 정책(Families Policy)을 따르나요? | 아니요 (해당 없음) |
| 이 앱이 독립 보안 검토를 받았나요? | 아니요 (오픈소스, 코드 공개) |

## 권한 사용 근거 (Permissions Justification)

| 권한 | 근거 |
|------|------|
| `INTERNET` | Android WebView 컴포넌트의 시스템적 요구사항. 실제 외부 통신은 수행하지 않음. 추후 업데이트(공지 알림 등)를 위해 보유. |

## 외부 인텐트 처리

본 앱은 `intent-filter`를 통해 외부 앱이 .hwp 파일을 본 앱으로 열도록 허용합니다.

- 외부 앱이 본 앱에 파일 URI를 전달할 때, 해당 URI는 일회성으로만 사용
- 파일 내용은 디바이스 내에서만 파싱·표시
- URI나 파일 내용을 외부로 전송하지 않음

## 데이터 안전 양식 작성 시 핵심 메시지

```
이 앱은 사용자가 명시적으로 선택한 HWP/HWPX 문서 파일을
디바이스 내에서만 파싱·표시합니다. 어떤 데이터도 외부로
전송하거나 제3자와 공유하지 않으며, 분석·광고 SDK가
포함되어 있지 않습니다. 모든 처리는 WebAssembly 기반으로
사용자 디바이스 내에서 완결됩니다.
```

위 문구를 영문 변환하여 "이 정보가 정확한 이유" (justification) 영역에도 동일하게 사용 권장.
